# banned.txt: the blog pipeline's banned list, as data, for lint.py.
#
# One rule per line:  <pattern> | <what to write instead>
# The separator is " | " (a pipe with a space on each side); inside a pattern,
# write alternations without spaces around the pipe: (?:a|b).
# Patterns are Python regexes, matched case-insensitively, one block at a time
# (a paragraph, list item, heading or table row), with ^ at the start of each
# line. lint.py straightens curly quotes and drops * before matching, so write
# apostrophes straight ('). Where two rules hit the same words, the first one
# in this file wins, so specific rules come before general ones.
# "#" starts a comment line. Blank lines are ignored.
#
# Sources: prompts\4-draft.md and prompts\5-edit.md ("Banned" and "Written, not
# transcribed"), then Wikipedia's "Signs of AI writing" page
# (https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing), read 2 Nov 2026.
# Counted rules (em dashes per 300 words, "So" openers, "It's not X, it's Y"
# more than once, section-opening rhetorical questions) are in lint.py itself.

# ---------- Openers (4-draft.md) ----------
^In today's | start with his concrete moment instead
^In the world of | start with his concrete moment instead
^In a world where | start with his concrete moment instead
^Have you ever\b | open on what happened to him, not a question to the reader
\blet's (?:dive|delve|explore|unpack|break (?:it|this) down)\b | cut it; start with the first real point
^Picture this\b | describe the scene he actually gave
^Imagine (?:a world|if|this)\b | describe the scene he actually gave
\b(?:dictionary defines|is defined as|defines \w+ as|according to (?:the )?(?:merriam-webster|webster|oxford(?: english)? dictionary))\b | open on his moment, not a dictionary definition

# ---------- Wikipedia: negative parallelisms and transitions ----------
\bnot (?:only|just|merely)\b[^.!?\n]*?\bbut(?: also)?\b | say both things plainly, in two sentences if needed
\bno \w+(?: \w+)?, no \w+(?: \w+)?, just\b | say what it is, plainly
(?:^|(?<=[.!?] ))(?:additionally|moreover|furthermore)\b | cut it, or use "also" or "and" inside the sentence
(?:^|(?<=[.!?] ))overall\b,? | cut it; the last point doesn't need a label
