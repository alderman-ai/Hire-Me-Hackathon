## Intro

Thirteen pieces of work, run by AI agents working in parallel, with Alex steering. First comes the tooling that lets the agents work on their own. Then come ten demos of what a GTM engineer builds, and they all end up on this site.

## How it runs

- **One plan at the top.** Alex wrote a project charter in the morning: the goal, the rules every agent follows, and the list of deliverables.
- **One agent per piece of work.** Each deliverable gets its own spec, a plan an agent can carry out on its own, and its own background Claude Code session. The sessions run at the same time and message each other.
- **One window for Alex's input.** Any agent that needs Alex sends its question to the "answer desk", a single window that shows him one question at a time.
- **Alex first, then overnight.** Anything that needs Alex (recordings, decisions, sign-offs) happens while he's at the computer today. The rest builds overnight, and a cleanup session follows tomorrow morning.
